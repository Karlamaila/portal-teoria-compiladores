Extras

Un analizador léxico que puedes probar, glosario, línea de tiempo, quiz y herramientas para construir compiladores.

Esta sección reúne material para practicar: una demo de analizador léxico escrita en JavaScript, un glosario con buscador, una línea de tiempo, un quiz con retroalimentación y herramientas reales para construir tus propios compiladores.

Ideas clave

  • La demo usa expresiones regulares, la misma idea teórica que usan los generadores léxicos.
  • El glosario cubre los términos que aparecen a lo largo del portal.
  • El quiz te muestra la explicación de cada respuesta apenas contestas.

Demo: analizador léxico

Escribe un fragmento de código o elige un ejemplo y pulsa Analizar. El programa lo divide en tokens con expresiones regulares, igual que la primera fase de un compilador. Reconoce palabras reservadas (int, float, char, void, if, else, while, for, return), identificadores, números, operadores y delimitadores.

Línea de tiempo

  1. 1957

    FORTRAN: se entrega el compilador del primer lenguaje de alto nivel ampliamente usado, desarrollado en IBM bajo la dirección de John Backus.

  2. 1958–1960

    ALGOL: el informe de ALGOL 60 popularizó la notación BNF para describir la sintaxis de un lenguaje.

  3. Mediados de los 70

    lex y yacc, en Unix, automatizan la creación de analizadores léxicos y sintácticos.

  4. 1987

    GCC: Richard Stallman publica la primera versión del compilador del Proyecto GNU.

  5. 1995

    Java y la JVM: se populariza la idea de compilar a bytecode y ejecutarlo en una máquina virtual.

  6. Principios de los 2000

    LLVM: nace en la Universidad de Illinois como infraestructura reutilizable para compiladores.

  7. 2008

    V8: Google lo presenta junto con Chrome, con compilación JIT de JavaScript.

  8. 2015

    Rust 1.0: primera versión estable del lenguaje, basado en LLVM.

  9. 2017

    WebAssembly: los principales navegadores incorporan soporte para ejecutar código compilado a este formato.

Herramientas para construir compiladores

Flex y Bison

Flex genera analizadores léxicos a partir de expresiones regulares. Bison genera analizadores sintácticos LR a partir de una gramática. Son las versiones libres de lex y yacc.

ANTLR

Genera lexer y parser a partir de una sola gramática y puede producir código en varios lenguajes de programación. Se usa mucho para lenguajes específicos de dominio.

JFLAP

Programa educativo para diseñar y simular autómatas finitos, autómatas de pila, gramáticas y máquinas de Turing. Es ideal para practicar lo visto en esta asignatura.

LLVM

Biblioteca para construir el middle-end y el back-end: optimizaciones y generación de código para muchas arquitecturas. Solo hace falta escribir el front-end del lenguaje.
